# KCD1（天国：拯救 1）本地化脚本

《天国：拯救 1》的汉化辅助工具。KCD1 的文本是**按文件拆开**的一堆 `text_ui_*.xml`，和 KCD2 的单文件 `text_ui_dialog.xml` 结构不同，所以单独放一个目录。

| 文件 | 作用 |
| --- | --- |
| `天国拯救_双语字幕.py` | 把中文原版 XML 逐文件生成「中文 / 英文」双语版（按行合并 Cell） |
| `天国拯救_文本修正.py` | 用对照表 + 内置修正字典修正中文文本（错译、人名统一等） |

## 用法

```bash
# 默认读脚本同目录下的 天国拯救语言文件/
python 天国拯救_双语字幕.py
python 天国拯救_文本修正.py

# 指定目录
python 天国拯救_双语字幕.py ^
  --input-dir  "天国拯救语言文件\中文原版" ^
  --output-dir "天国拯救语言文件\双语版" ^
  --source     "天国拯救语言文件\text__ChineseUpdated_source.xml"
```

翻译源是 `Row/Cell[1]`（原文）与 `Cell[3]`（中文）的对照表；修正字典直接写在脚本里（人名统一、错译修正，约 40 条）。

## 数据不入库

`天国拯救语言文件/` 里是游戏原文与中文文本，**版权归开发商所有，不进仓库**。仓库只保留脚本；把合法的游戏文本放到 `天国拯救语言文件/` 下即可运行。
